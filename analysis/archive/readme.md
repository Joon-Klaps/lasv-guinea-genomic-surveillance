# Archive of earlier analyses

`run-Simon/LASV_L_alignment_6.xml` and `run-Simon/LASV_S_alignment_6.xml` are the BEAST input files of an earlier phylogeographic analysis, which used alignment version 6 of each segment. `../data-preprocessing/metadata-curation.ipynb` reads the sequence names in them to find out which sequences were part of that alignment.
